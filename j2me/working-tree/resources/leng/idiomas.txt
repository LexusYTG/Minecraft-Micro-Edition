# ============================================================
# Arriba va la lista de idiomas:  lang[ID]=Nombre  (ID entre 0 y 127).
# Despues, un bloque por idioma que empieza con [ID].
#
# FORMATO
#  - Las lineas vacias y las que empiezan con # se ignoran.
#  - Tambien se puede comentar al final de una linea: un espacio y un #.
#    (por eso un texto no puede contener ' #').
#  - Dentro de un bloque cada linea es   ID_DE_TEXTO=texto
#       1 a 999    textos de la interfaz (menus, avisos, teclas...)
#       1000 + N   nombre del bloque o item numero N  (1001 = Pasto, 1002 = Tierra...)
#  - Si a un idioma le falta una linea, el juego usa el texto en espanol.
#  - No hace falta dejar espacios al final: si el texto original termina en
#    espacio (por ejemplo 'Nombre: ') el juego lo agrega solo.
#  - Si el telefono no tiene en su fuente alguna letra (acentos, cirilico...),
#    esa letra puede verse como un cuadrado: probar en el dispositivo.
#
# PARA AGREGAR UN IDIOMA SIN TOCAR EL CODIGO
#  1) Arriba, agregar una linea  lang[ID]=Nombre  con un ID libre.
#  2) Al final del archivo, copiar un bloque completo (por ejemplo el de
#     English), cambiar su encabezado a [ID] y traducir los textos.
#  3) Volver a armar el JAR con la carpeta leng/ adentro.
#  En el juego: Pausa > Idioma cambia entre los idiomas de la lista.
# ============================================================
